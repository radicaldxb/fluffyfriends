# Site favicon and app icons

All site icons live in this folder and are referenced from `app/layout.tsx`.

**Current files:**
- `favicon.svg` – default favicon (used by layout)

**Optional (add for best compatibility):**
- `favicon.ico` – classic favicon (e.g. 32×32 or multi-size)
- `icon-light-32x32.png` – light theme icon
- `icon-dark-32x32.png` – dark theme icon  
- `apple-touch-icon.png` – Apple touch icon (e.g. 180×180)

Replace or add these files here; the app will pick them up from `/image/...`.
